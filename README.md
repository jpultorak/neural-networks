# 2025/2026 **Neural Networks** class
## University of Wroclaw 


### Assignments

1. Introduction to Torch; Using pretrained `ResNet18` for image classification.
2. Linear regression; Pytorch's `autograd`; Manual training loop and learning rates;
3. Manual gradient computation and comparison with Pytorch's `autograd`; Solving binary classification on `Fashion-MNIST` with Logistic regression 
and MLP with one and two hidden layers;
4. Solving CIFAR-10 with MLP's implemented with `torch.nn.Module`, `torch.nn.Sequential`; mini-batches; Comparison
    of different optimizers: **SGD**, **SGD + Momentum**, **SGD + Nesterov**. **RMSprop**, **Adam**
